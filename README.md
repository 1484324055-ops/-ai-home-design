# AI Home Design

全屋定制AI效果图生成器 - 为全屋定制行业从业者提供专业的AI生图提示词生成工具。

## 功能特性

- 🏠 **智能级联选择**：空间 → 柜体 → 风格 → 材质，自动过滤不匹配选项
- 🎨 **5套主题切换**：日间明亮、深夜专注、品牌原木、专业深色、极简黑白
- 📝 **中英对照提示词**：生成专业的中英文AI生图提示词
- ✏️ **可编辑**：支持二次创作，自由修改提示词内容
- 📋 **一键复制**：分别复制中文或英文完整提示词
- 🔄 **重置功能**：快速恢复初始状态
- 🔐 **用户认证**：注册登录，保护个人配置
- 📱 **响应式设计**：适配桌面和移动设备

## 技术栈

- **前端**: Next.js 14 + React 18 + TypeScript + Tailwind CSS
- **后端**: Next.js API Routes + Prisma
- **数据库**: PostgreSQL (生产) / SQLite (开发)
- **认证**: bcryptjs + jose (JWT)

## 快速开始

### 本地开发

```bash
# 克隆项目
git clone <repository-url>
cd ai-home-design

# 安装依赖
npm install

# 配置环境变量
cp .env.example .env

# 设置数据库（开发环境使用 SQLite）
npx prisma migrate dev

# 启动开发服务器
npm run dev
```

访问 http://localhost:3000

### 部署到 Vercel

1. 注册 [Vercel](https://vercel.com) 账号
2. 安装 Vercel CLI: `npm i -g vercel`
3. 登录: `vercel login`
4. 配置 PostgreSQL 数据库（推荐 [Neon](https://neon.tech)）
5. 设置环境变量:
   - `DATABASE_URL`: PostgreSQL 连接字符串
   - `JWT_SECRET`: 随机密钥
6. 部署: `vercel --prod`

详细部署指南见 [DEPLOY.md](./DEPLOY.md)

## 使用指南

1. **注册/登录**：创建账号或登录现有账号
2. **选择空间**：点击选择要设计的房间类型
3. **选择柜体**：根据空间自动过滤可用的柜体类型
4. **选择风格**：选择设计风格
5. **选择材质**：根据风格自动过滤可用的材质
6. **高级选项**（可选）：调整住宅类型、镜头、光影
7. **生成提示词**：点击生成按钮
8. **编辑/复制**：可编辑提示词，一键复制中文或英文版本
